# TAIKA

Web estàtica de les figuretes TAIKA.

## Estructura

- `TAIKA · Figuretes 3D fetes a mà.html`: entrada i contingut de la web.
- `styles.css`: estils i disseny.
- `app.js`: carrusel, filtres i interaccions de la col·lecció.
- `assets/`: logo i imatges de les figuretes.
- `assets/PLUJA36fps/`: 150 fotogrames originals de la Pluja.
- `assets/pluja-scroll/`: fotogrames 1–72 optimitzats; el 72 coincideix amb el centre del carrusel.

## Previsualització local

Des de la carpeta del projecte, inicia un servidor local:

```sh
python3 -m http.server 8000
```

Obre `http://localhost:8000/TAIKA%20%C2%B7%20Figuretes%203D%20fetes%20a%20m%C3%A0.html` al navegador. Atura el servidor amb `Ctrl+C`.
